# References

Sources below were opened on official publisher, catalog, or government pages
for this documentation draft. Draft ADRs are not final. If a candidate could
not be verified independently, it is omitted.

ISO.org’s HTML catalog for ISO/IEC 27001:2022 (standard 82875) was not
retrieved here because of a Cloudflare challenge. The joint publication is cited
from the IEC Webstore listing instead.
