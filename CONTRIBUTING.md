# Contributing

This repository is the GRC leaf. It owns policy, control, risk, evidence, and
compliance-audit truth. It does not require a sibling checkout of naruon, gyeot,
or any other CWL home.

## Customer README

Keep [`README.md`](README.md) for customers and operators of the GRC product.
Describe policy, control, risk, evidence, and compliance-audit truth. Do not
turn the README into an agent work manual.

## Architecture decision records

Add product decisions under [`docs/adr/`](docs/adr/README.md). Each ADR stays a
draft until a human accepts it. Use Context, Decision, Consequences, and APA 7th
references with a DOI or official URL.

Cite only sources that can be opened on an official catalog, publisher, or
government page. If a candidate cannot be verified independently, omit it.

Do not invent a runtime, package, catalog database, or test harness on a
documentation-only change.

## Personal data

Do not prescribe masking. Authorized officer and user data stay usable under
purpose-bound access control, encryption, and audit.
